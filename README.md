# 知屿文档：本地个人知识库

一个运行在自己电脑上的个人知识库，用来记录笔记、连接知识、主动复习和练习面试。文档编辑区采用左侧文档树、正文与大纲并排的布局，支持浅色与深色主题。

使用本地账号登录，文档保存在 SQLite 中，不需要云数据库或第三方账号。知识问答、复习、知识体检和版本管理在本机完成；模拟面试可选接入 DeepSeek 或 OpenAI，未配置时也能使用本地规则出题。

完整迭代记录见 [`CHANGELOG.md`](./CHANGELOG.md)。

## 已实现

- 首页索引与最近编辑，知识库和四个知识工具各有独立页面
- 简约登录页、首次设置本地账号、七天登录状态与退出登录；文档接口和本地图片需要登录后访问
- 富文本块编辑器：标题、列表、待办、代码块、图片等由 BlockNote 提供
- 无限层级的文档与子文档；同级文档可以拖动排序
- 标题和正文自动保存；快速切换文档不会串写内容
- `Ctrl + K` 全文搜索
- 标签管理、标签筛选与最近编辑搜索
- 文档栏底部提供回收站、恢复与一键永久清空
- 文档锁定：一键锁定当前文档及全部子文档，服务端禁止修改内容、重命名、移动、排序、删除及新建子文档；再次点击锁图标即可解除
- 默认导出当前文档，可切换全量 JSON/Markdown 备份并进行二次确认
- Markdown 与普通 JSON 文件导入，可指定为顶级文档或任意文档的子文档
- 正文图片本地上传与插入
- 大纲跟随正文滚动，支持 1—6 级标题层级与完整标题提示
- 文档栏和大纲栏可折叠、拖动调整宽度；大纲列表独立滚动，顶部标题和收起按钮保持可见
- 本地 SQLite 数据库，重启服务或电脑后文档仍保留
- 双向链接：输入 `[[` 搜索文档，正文下方自动显示引用与反向引用
- 主动复习：学习状态、到期清单、先回忆再展开正文，并按掌握程度安排复习
- 知识问答：从本地笔记中组合答案，列出文档、章节和内容块出处
- 模拟面试：按章节知识点出题，LLM 只选取、重排已有文档答案，作答后即时展开；主动追问时再调用大模型，未配置模型时使用笔记原文作为参考
- 知识体检：检查重复标题、失效或含糊链接、未解释概念和长期草稿
- 版本时间轴：自动保留文档快照，支持预览和可逆恢复

## 页面入口

登录后进入首页，可从“我的知识库”继续编辑，也可以直接使用知识工具。各页保留导航，支持浏览器前进与后退。

| 页面 | 本地路径 | 用途 |
| --- | --- | --- |
| 首页 | `/` | 知识库入口、四个知识工具和最近编辑 |
| 我的知识库 | `/documents` | 文档树、富文本编辑、搜索、大纲和复习 |
| 知识问答 | `/tools/ask` | 检索本地笔记、查看出处、将答案整理为新笔记 |
| 模拟面试 | `/tools/interview` | 选择笔记、练习作答、查看原文答案和主动追问 |
| 知识体检 | `/tools/health` | 查找重复内容、失效链接与待整理笔记 |
| 版本时间轴 | `/tools/versions` | 选择文档、预览历史版本并恢复 |

旧版 `/?document=文档ID` 链接仍可直接打开文档；当前文档链接也支持 `/documents?document=文档ID`。

## 启动

前提：安装 Node.js 22.13 或更新版本（推荐 Node.js 24），需要内置的 `node:sqlite` 支持。首次安装依赖需要联网。

使用 Git 获取项目并安装依赖：

```powershell
git clone https://github.com/pixel-liu/zhiyu-knowledge-base.git
cd zhiyu-knowledge-base
npm install
```

如果已经下载或克隆项目，只需在包含 `package.json` 的目录执行 `npm install`。

之后有两种启动方式：

1. 双击 [`启动知识库.bat`](./启动知识库.bat)，默认运行正式版本。
2. 在项目目录执行：

```powershell
npm run start:local
```

首次启动会自动构建；之后直接复用构建，避免开发模式访问页面时的编译等待。代码、配置或依赖清单更新后会自动重新构建，无需手工删除缓存。首次升级到此启动方式也会构建一次，请等待窗口显示“知识库已就绪”。构建失败会保留窗口和错误信息。

浏览器打开 <http://127.0.0.1:3000>。终端窗口不要关闭；按 `Ctrl + C` 可以停止服务。重复双击会提示已有服务；端口被其他程序占用时会明确提示。服务仅监听本机地址。

也可以直接双击 [`关闭知识库.bat`](./关闭知识库.bat) 一键关闭本项目启动的服务，支持正式模式与开发模式，只匹配当前项目目录下的启动器及 Next 进程树。

修改代码时，使用 [`开发知识库.bat`](./开发知识库.bat) 或 `npm run dev -- --hostname 127.0.0.1` 启用热更新。切换模式前请先关闭已有服务。

可在 PowerShell 中设置端口或独立数据目录，再启动：

```powershell
$env:PORT = "3001"
$env:ZHIYU_DATA_DIR = "D:\ZhiyuData"
npm run start:local
```

这两个设置均为可选项，默认端口为 `3000`，默认数据目录为项目下的 `data/`。`ZHIYU_DATA_DIR` 会改变文档、账号和模型配置的位置；上传图片仍保存在项目的 `public/uploads/`。

首屏先显示文档库框架和目录，编辑器单独加载，并与文档请求并行获取。目录接口只返回元数据，正文按需获取并缓存最近打开的文档，减少首次传输和解析量。

## 登录

首次访问会进入账号设置页，设置自己的账号（2–40 个字符）和密码（8–128 个字符），随后进入首页。没有默认账号或密码，原有文档会完整保留。之后使用这个账号登录，登录状态保留七天；右上角的退出图标会先完成待保存的修改，再退出登录。

这是单人文档库，同一数据目录只设置一个账号。密码经过随机盐与 scrypt 处理，账号及会话保存在 `data/auth.db`，不会提交到 Git；浏览器通过 HttpOnly Cookie 保存会话凭据。文档、备份、搜索、导入、上传及图片访问均需要登录。

备份文档内容仍使用 JSON/Markdown 或 `knowledge.db`。若要连同登录账号迁移，请停止服务后同时备份 `auth.db`。忘记账号或密码时，停止服务，把 `data/auth.db`（以及存在的 `auth.db-wal`、`auth.db-shm`）移到安全的备份位置，再启动并重新设置账号；此操作会让所有旧登录状态失效，不影响 `knowledge.db` 中的文档。请勿在服务运行时移动数据库。

使用 `ZHIYU_DATA_DIR` 时，账号和文档一起放在指定的数据目录。首次设置前请保持默认的本机监听地址；当前功能用于本地单人使用。

## 数据与备份

默认的数据位置如下，均已被 Git 忽略：

| 路径 | 内容 |
| --- | --- |
| `data/knowledge.db` | 文档、标签、关联目标、复习计划和版本快照 |
| `data/auth.db` | 本地账号和登录会话 |
| `data/ai-interview.json` | 在页面保存的模型配置和 API Key（配置后创建） |
| `public/uploads/` | 上传到正文的本地图片 |

文档数据库不会自动上传到云端。启用外部模型时，模拟面试会按下方说明发送相关内容。

右上角“更多功能”可以导出 JSON 或 Markdown。默认只导出当前文档；开启“全量备份”后会导出整个文档库，执行前均会再次确认。JSON 备份可通过“导入备份”恢复到当前文档库。

JSON 备份包含文档、关联目标、复习计划和版本快照；Markdown 适合阅读和迁出正文。两种导出均不打包图片文件，也不包含登录账号或 API Key。迁移带图片的文档时，需要同时复制 `public/uploads/`，保留文件名与目录结构。

如需完整迁移，先停止服务，再备份整个 `data/` 和 `public/uploads/`；使用自定义数据目录时，备份该目录及项目下的 `public/uploads/`。迁移模型配置会一并携带 API Key，请妥善保存。仅需备份知识内容时，可单独复制 `knowledge.db` 和图片目录。

## 文档关联与主动复习

在正文中输入 `[[`，按标题查找并选择文档，即可插入链接。也可以完整输入 `[[文档名]]`：只有一个同名目标时会自动转换；存在同名文档时保留原文并提示选择。候选项显示父文档和标识后缀，方便区分。链接绑定文档 ID，目标改名后仍可跳转；普通点击在当前页面打开，修饰键点击可另开标签页。引用与反向引用显示在正文下方，移入回收站的文档会隐藏，恢复后重新显示；代码块和行内代码不会产生引用。

在正文顶部的文档标题右侧点击“加入复习”，加入后显示“已加入复习”；文档下方可切换“学习中 / 待巩固 / 已掌握”。右上角的“今日复习”入口会显示到期数量；可以查看到期清单或全部计划。进入复习后先尝试回忆，再点击“展开正文，对照回忆”，最后记录掌握程度：

- 没想起来：10 分钟后再看。
- 有些模糊：明天巩固。
- 基本记得：按 1、3、7、14、30、60、120 天逐步延长间隔。
- 很熟悉：跳到更长的复习间隔，至少一周。

“暂不复习”可将文档移出计划；文档移入回收站时暂停显示，恢复后保留原计划。JSON 备份包含复习计划和关联目标，导入时会重映射重复的文档 ID；旧版 JSON 备份仍可导入。Markdown 导出保留 `[[文档名]]` 文本，适合阅读，完整计划请使用 JSON 或 SQLite 备份。复习中的正文以只读文本展示，图片保留提示，可通过“打开原文档”查看完整排版。

## 知识工具

从首页或顶部导航进入对应的独立工具页面。知识问答、知识体检和版本时间轴在本机处理；模拟面试可选择接入大模型。

- **知识问答**会按问题中的关键词检索正文内容，组合最相关的笔记片段，并列出原文档、章节和内容块位置。点击出处即可打开对应文档并定位内容，也可以把问答整理为新笔记。它只依据已经写下的内容回答，没有匹配时会明确提示。
- **模拟面试**可选择最多 20 篇笔记。配置大模型后，按完整章节提取正文、列表、代码块和表格，跳过只有标题的空章节。模型直接围绕知识点提出面试问题，只选取、重排对应章节的原文作为答案；服务端验证每段答案都能在原文中找到，不允许另写答案或解析。作答前隐藏答案，提交后直接在下方展开，不调用模型、不自动评分。你可以在答案下面输入追问；只有点击“发送追问”时，才会结合当前题目、笔记、参考答案、你的回答和最近八轮追问调用模型。切换下一题后清空该题的追问区。未配置密钥或出题接口不可用时，使用本地问题和笔记原文作为参考答案，并说明降级状态；追问失败保留输入内容和参考答案，方便重试。
- **知识体检**扫描重复标题与正文、目标已删除的链接、无法确定目标的同名链接、尚无对应文档的概念，以及超过 30 天未整理的短草稿。每项结果都能直接打开相关文档处理。
- **版本时间轴**记录标题和正文快照。连续输入在 5 分钟内合并为一个版本，每篇文档最多保留 60 个版本；恢复旧版本前的当前内容仍会留在时间轴中，因此可以再次恢复。

JSON 备份格式已升级到第三版，完整包含版本快照，并继续兼容缺少版本数据的旧备份。导入旧备份时会为每篇文档创建初始快照。

### 配置大模型模拟面试

在“模拟面试”页面右上角点击“配置 API Key”，选择服务商并保存，也可调整模型名称和接口地址。配置立即应用于下一次出题或追问，无需重启；密钥保存在本机服务端的 `data/ai-interview.json`（或自定义数据目录下的同名文件），保存后接口不会回传密钥，也不会写入文档数据库或随文档备份导出。若使用页面配置，它会优先于下方的环境变量；可随时在同一处移除，随后恢复环境变量配置或本地规则。

在项目根目录新建 `.env.local`（该文件已被 Git 忽略），可以使用 DeepSeek：

```dotenv
DEEPSEEK_API_KEY=你的_DeepSeek_API_密钥
DEEPSEEK_MODEL=deepseek-flash
DEEPSEEK_BASE_URL=https://api.deepseek.com
```

也可以使用 OpenAI：

```dotenv
OPENAI_API_KEY=你的_API_密钥
OPENAI_MODEL=gpt-4o-mini
OPENAI_BASE_URL=https://api.openai.com/v1
```

环境变量配置需要重启知识库。上面列出的是项目代码中的默认模型和地址，可按自己账号可用的模型修改；如果同时配置两种密钥，优先使用 DeepSeek，OpenAI 接入使用 Responses API。连接超时、网络中断或服务临时异常时，会在总计 45 秒的请求时限内自动重试一次；仍然失败时，页面会说明超时、密钥验证、余额或模型配置等具体原因，并回退到本地规则。

接入后，开始模拟面试会把本轮选中笔记的相关片段发送给配置的模型服务；仅在主动发送追问时，才会同时发送当前题目、参考答案、你的回答和最近八轮追问。其他知识工具仍在本机处理。若希望笔记内容始终留在本机，保持页面与环境变量中的模型密钥均未配置即可。

## 开发与验证

| 命令 | 说明 |
| --- | --- |
| `npm run dev -- --hostname 127.0.0.1` | 启动本机开发服务，支持热更新 |
| `npm run start:local` | 自动检查构建并启动本机正式版本 |
| `npm run build` | 生成 Next.js 正式构建 |
| `npx tsc --noEmit` | TypeScript 类型检查 |
| `npm test` | 运行单元测试 |
| `npm run test:auth` | 正式版本端到端验证，需先执行构建 |
| `npm run lint` | 运行 ESLint |

`test:auth` 使用独立临时数据目录和临时端口，验证登录、文档访问、双向链接、复习及备份流程，不使用日常文档数据库。
